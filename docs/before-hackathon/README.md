# Before the hackathon

State of the live app ([propchange.vercel.app](https://propchange.vercel.app)) on **25 Nov 2026**, before the
Dev3pack Global Hackathon (27–29 Nov 2026). The matching code is tagged
[`pre-dev3pack`](https://github.com/dimitrijnemesh/propchange/tree/pre-dev3pack).

Everything after that tag was built during the hackathon — compare with
[`pre-dev3pack...main`](https://github.com/dimitrijnemesh/propchange/compare/pre-dev3pack...main).

At this point the app is a front-end prototype on demo data: Phantom wallet connect works, but there is no
Solana program yet (Seat mint, USDC escrow and refund are simulated).
